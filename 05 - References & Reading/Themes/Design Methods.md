# Design Methods

Methodological grounding for the Symbiosis project — frameworks for designing and evaluating human-AI systems, and approaches that go beyond conventional usability testing.

---

## Core Papers

- [[Human-Centered AI — Shneiderman 2020]] — HCAI principles: reliable, safe, trustworthy
- Usability Evaluation Harmful — Greenberg 2008 *(no paper note yet)* — challenges to standard usability evaluation; when it misses the point
- [[Design Frictions — Cox 2016]] — intentional friction as a design tool for mindful interaction
- [[Research-through-Design GenAI — Benjamin 2024]] — RtD as response to GenAI; exploratory study methodology
- [[Research through Design Fiction — Blythe 2014]] — fiction as empirical method; theoretical grounding for design fiction
- [[Conversational Agent vs Direct Manipulation — Jönsson 2005]] — empirical comparison of NL vs. DM; control and efficiency trade-offs
- [[Questioning the AI — Liao 2020]] — XAI as user requirements; designers specify what explanations users need
- [[Hidden Layer Interaction — Grabe 2025]] — technique for exploring GenAI as a material
- Sciences of the Artificial — Simon 1996 *(no paper note yet)* — foundational: design as creation of artifacts that mediate human intent
- Prompt Machine Tangible AI — Lindrup 2025 *(no paper note yet)* — tangible AI tool for children; physical interaction design

## Methods Particularly Relevant to This Project
- **Research-through-Design** (Benjamin 2024) — appropriate for early-stage, exploratory pre-thesis work
- **Breaching experiments** (Crabtree 2004) — surface assumptions by breaking them
- **Somaesthetic inquiry** (La Delfa 2024) → see [[Symbiosis & Embodiment]]
- **Ethics of care** (Hsu 2025) → see [[Human-Robot Interaction]]

## Design Principles for Embodied AI
From [[Design Frictions — Cox 2016]]: friction creates moments of reflection in otherwise seamless tech use → relevant for designing embodied AI that doesn't become parasitic.

From [[Hidden Layer Interaction — Grabe 2025]]: treating GenAI as a *material* to be worked with, not a black box.
