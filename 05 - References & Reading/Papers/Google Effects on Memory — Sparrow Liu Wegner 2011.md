# Google Effects on Memory — Sparrow Liu Wegner 2011

**Authors:** Betsy Sparrow, Jenny Liu, Daniel M. Wegner
**Year:** 2011
**Source:** Science, 333(6043), 776–778

---

## Summary
Three experiments demonstrating that the availability of information via Google changes how people encode it — they remember where to find information rather than encoding it directly, offloading memory to the external system. Introduces transactive memory with machines: cognitive architecture adjusts to incorporate available external systems as memory partners. People are less likely to remember information they believe will be available digitally.

## Relevance to Symbiosis
Individual-level mechanism behind the substitution track. If cognitive offloading to Google atrophies memory, offloading relational and cognitive functions to AI may atrophy the capacities those functions previously required — judgment, social knowledge, conversational skill. Provides empirical grounding for the scaffolding-vs-substitution distinction applied to cognitive rather than task-level capacity.
