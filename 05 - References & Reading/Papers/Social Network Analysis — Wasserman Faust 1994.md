# Social Network Analysis — Wasserman Faust 1994

**Authors:** Stanley Wasserman, Katherine Faust
**Year:** 1994
**Source:** Cambridge University Press

---

## Summary
The standard reference textbook for social network analysis. Covers foundational network concepts, measures (centrality, clustering coefficient, density, betweenness), data collection methods, and analysis approaches. Defines the core vocabulary of SNA and provides the mathematical and statistical basis for network-level claims. Covers both sociocentric (whole network) and egocentric (ego network) analysis.

## Relevance to Symbiosis
Primary methods reference for the network analysis component of the Social Dynamics of AI study. All sociogram-based measures — betweenness centrality of AI nodes, clustering coefficient of human subgraphs, edge weight distribution — are defined and justified with reference to this text.
