# Trusting Virtual Agents: The Effect of Personality — Zhou 2019

**Authors:** Michelle X. Zhou, Gloria Mark, Jingyi Li, Huahai Yang  
**Year:** 2019  
**Venue:** ACM Transactions on Interactive Intelligent Systems  
**DOI:** https://doi.org/10.1145/3232077

---

## Summary
Empirical study of how personality traits of virtual agents affect user trust. Finds that agent personality (not just competence) significantly influences trust — extroversion, warmth, and perceived similarity to the user increase trust.

## Relevance to RQs
- **RQ2** — directly measures trust in virtual embodied AI; personality affects rapport and willingness to comply
- **RQ1** — users develop mental models that include agent personality as a trust cue

## Key Concepts
- Trust in virtual agents
- Agent personality
- Perceived similarity
- Extroversion / warmth as trust cues
- Virtual embodiment
