# 09 — Design in the Age of AI

A talk and a podcast episode exploring the same core argument from two angles: UX inherited the methods of its parent disciplines (HCI, psychology, engineering) without inheriting the rigour, and AI has widened that gap. The fix isn't more AI — it's reconnecting with the research lineage, and rebuilding the "translator" role that turns observation into usable knowledge.

## Folder structure

```
presentation/      Current talk deck, script, and the assets that build it
podcast/            Podcast script for The Point of Interface
fieldwork/          Raw source material: handwritten notes + their summary
archive/            Superseded draft deck and the script that generated it
```

### `presentation/`
- **`Design Research in the Age of AI.pptx`** — the current, full deck (45 slides). This is the one in active use.
- **`Script.md`** — talk outline and speaking script for the deck above.
- **`Roots of UX (2).html`** — standalone interactive lineage-map artifact (dark "departure board" visual), referenced from the deck's "Reference · Roots of UX" slide.
- **`restructure.py`** — one-off script that reordered slides in the pptx above (observations before the pivot, Roots of UX moved next to the knowledge-problem section, etc.). Kept for reference; re-running it against the current file will re-apply that reordering.
- **`charts/`** — the four concept-map/diagram PNGs embedded in the deck, plus `charts.py`, the matplotlib script that generates them.

### `podcast/`
- **`Where did all the translators go.md`** — script for *The Point of Interface* podcast episode. Covers the same translator/rigour argument through the Renaissance-translator analogy instead of the talk's three-observations structure. Includes a "Check before recording" section with fact-check notes (sources: Don Norman attribution, Donatello's timeline, the Johansson/Sky story, etc.) — last verified 2026-10-13.

### `fieldwork/`
- **`notes.md`** — typed breakdown of the handwritten notes below, organized into five themes (trust economy, the floor/ceiling paradox, upstream/downstream translation, historical framing, reflective questions).
- **`fieldwork-notes-01/02/03.png`** — photos of the original handwritten sketches (designer–user network diagrams, etc.) that `notes.md` summarizes and that fed the "Human Framework" chart in the deck.

### `archive/`
- **`Design in the Age of AI.pptx`** — an earlier, 13-slide draft of the deck. Superseded by `presentation/Design Research in the Age of AI.pptx`; kept for history.
- **`create_presentation.py`** — the script that generated the draft above. Paths have been updated to still run (pulls chart images from `presentation/charts/`, writes output back into `archive/`), but it's not the script behind the current deck.

## Notes on provenance

- The current deck was NOT generated by `create_presentation.py` — that script only ever produced the 13-slide `archive/` draft. The 45-slide current deck was restructured in place by `restructure.py` but otherwise built outside this repo (Keynote/PowerPoint).
- If regenerating charts, run `charts/charts.py` from this folder — it writes directly into `presentation/charts/`.
